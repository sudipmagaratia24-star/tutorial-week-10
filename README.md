```
A cloud computing service is a way of using computing resources—such as servers, storage, databases, networking, software, and processing power—over the internet (the cloud) instead of owning and managing physical hardware or software on your own computer.
Following are the type Cloud Computing Service:

1. Infrastructure as a Service (IaaS)
= IaaS provides basic computing infrastructure such as virtual machines, storage, networks, and servers over the internet.examples:Amazon EC2 – renting virtual servers to host websites,Google Compute Engine – running applications on virtual machines, Microsoft Azure Virtual Machines – creating and managing online servers



2. Platform as a Service (PaaS)
= PaaS provides a ready-made platform for developers to build, test, and deploy applications without worrying about hardware or system setup.examples:Google App Engine – developing and deploying web apps, Heroku – hosting applications with minimal setup,Microsoft Azure App Service – building and running web/mobile apps


3. Software as a Service (SaaS)
= SaaS provides fully functional software applications over the internet that users can access through a web browser.
examples:Gmail – email service,Google Drive – cloud storage and file sharing,Microsoft 365 – Word, Excel, and PowerPoint online,Zoom as video conferencin



```
